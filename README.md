# scBURST

Growth-dependent diffusion SDE for unbalanced optimal transport.

## Example

A bundled notebook example based on the synthetic three-gene dataset with `alpha = 0.5` is included under `examples/`.

Open from the repo root:

- `examples/three_gene_alpha05.ipynb`

Input data:
- `examples/data/three_gene_scburst_alpha05_data.csv`

The notebook trains the model and displays training, prediction, trajectory, birth-rate, and potential figures inline.
